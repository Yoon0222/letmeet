## ① 운영 DB — `docs/PROD_APPLY_4.2.0_ALL.sql` (사용자)

담긴 것(한 트랜잭션, 다시 실행해도 안전):
- **0101** 단체전 팀의 소속 클럽 + 용병(검사 트리거), 대회 목록의 단체전 참가 수를 팀 수로
- **0102** 단체전 오더: 한 대결에서 한 선수는 한 게임만(최종 제출 때 확인), 오류 문구 한국어
- **0103** 단체전 팀 최소 인원 = 단식 수 + 복식 수×2 이상으로 보정, 단체전 종목 배지를 대결 구성에서 정함

실행(둘 중 하나):
- 운영 Supabase SQL Editor 에 파일 전체를 붙여 넣고 Run
- `npx supabase db query -f docs/PROD_APPLY_4.2.0_ALL.sql --linked --project-ref jbvtdthtmrlndduqiikj`

확인 — 맨 아래 쿼리의 값이 열 이름 끝의 `expect_` 값과 같아야 한다:
`m0101_team_club true` · `m0101_member_guest true` · `m0101_guard_triggers 2` · `m0101_view_counts_teams true` ·
`m0102_set_checks_member true` · `m0102_submit_blocks_dup true` · `m0103_trigger true` · `m0103_short_teams 0` · `m0103_wrong_discipline 0`

영향: 지금 깔린 앱(4.0.0)도 그대로 동작한다(클럽을 고르지 않은 단체전 신청도 받음). 같은 선수를 두 게임에 넣은 오더는 제출 때 거절된다. 운영에는 대회가 없어서 바뀌는 기존 데이터는 없다.

```
cd web-admin
npx vercel --prod --yes
```
- 반드시 `web-admin` 폴더에서(루트에서 하면 다른 프로젝트라 실패). pinut.org·admin.pinut.org 는 새 배포를 자동으로 가리킨다.
- **①보다 먼저 배포하면 안 된다** — 새 신청현황 화면이 0101 의 새 열(소속 클럽·용병)을 읽어서, 없으면 팀 목록이 비어 보인다.

- 확인: admin.pinut.org 로그인 → 대회 만들기에서 진행 방식 '단체전' → 복식 3 으로 바꾸면 팀 최소 인원이 6 으로 맞춰짐.

## ⑤ (대회 신청을 받기 전) 최소 버전 올리기 — 선택

4.0.0 앱은 단체전 화면 글씨가 어두운 배경에 묻히고 소속 클럽 선택이 없다. **4.2.0 이 두 스토어에 모두 공개된 뒤에** 운영 SQL Editor 에서:
```sql
update public.app_config set min_version = '4.2.0', updated_at = now() where id = 1;
```
주의: 옛 앱은 모든 기능이 막히고 업데이트 안내만 뜬다 — 스토어에 4.2.0 이 열리기 전에 올리면 아무도 앱을 못 쓴다.

## ⑥ 실제 대회 만들기 (관리자 웹)

- 대회 만들기 → 진행 방식 **단체전**, 타이당 단식 0 · 복식 3(팀 최소 6명은 자동), 참가비, 접수 마감, 장소·시작 시각

**App Store (전체)**
```
피넛 4.2.0 업데이트

• 대회 화면을 새롭게 정리했어요 — 대회 정보·참가 현황·코트를 한눈에 볼 수 있어요

• 단체전 오더: 한 선수는 한 대결에서 한 경기만 나갈 수 있어요 — 겹치면 바로 알려 드려요

• 번개 모임을 링크로 공유할 수 있어요 — 앱이 없어도 웹에서 모임 정보를 볼 수 있어요

• 모임을 만들 때 날짜·시간 선택이 잘 보이도록 고쳤어요(iOS)
• 실력 범위(최소·최대)를 다시 설정할 수 있어요

[그 밖에]
• 이벤트(챌린지)에 참여하는 화면이 생겼어요 — 이벤트가 열리면 홈에 보여요
• 회원 탈퇴가 되지 않던 문제를 고쳤어요
• 자잘한 오류 수정과 안정성 개선
```
