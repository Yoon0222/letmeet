# 자료·이벤트 노션 로그

피넛의 **대외 산출물과 이벤트·홍보 활동**을 한 곳(노션)에 계속 쌓아 "뭘 만들었고 어떤 이벤트를 돌렸는지" 잊지 않게 한다. (로컬 `docs/WORKLOG.md` 는 코드/결정 기록 — 역할이 다르다.)

## 언제 기록하나 (놓치지 말 것)
아래를 **완료하면 매번** 이 스킬로 등록한다. 사용자가 시키지 않아도 끝나면 바로 남긴다:
- 영업/제안 **덱·문서** 산출 (예: 종합 영업 덱, 코트 입점 영업 덱, 지자체 대회 제안)
- **계약서/약관** 초안 산출 (예: 코트 입점 계약서)
- **이벤트/프로모션** 등록 (예: 앱 이벤트 모달 `event_popups`, 경품 추첨, 할인·무료 혜택)
- **홍보 메시지/카피** 작성 (예: 클럽 유치 메시지, 문자·카톡·SNS 문구)
- 사용자가 "노션에 등록/기록/자료 정리" 라고 할 때

## 대상 노션 페이지
- 제목: **피넛 — 자료·이벤트 로그**
- 찾기: `notion-search "피넛 자료 이벤트 로그"` (또는 "피넛 자료") 로 검색.
- 없으면: 워크스페이스 최상위에 같은 제목으로 새로 만들고, 맨 위에 한 줄 안내 blockquote("피넛 대외 자료·이벤트·홍보 기록. 최신이 위.")를 둔다.
- 페이지 ID를 처음 확정하면 이 파일의 이 줄에 적어 재검색을 줄인다 → ID: `(미확정)`

## A) 항목 추가 (기본 동작)
1. `notion-fetch` 로 페이지를 읽어 같은 제목·날짜 항목이 이미 있는지 확인(중복 방지).
2. `notion-update-page` (command: `insert_content`, position: `{"type":"start"}`) 로 **최상단**에 새 항목을 추가 → 최신이 위로.
3. 항목 형식:
```markdown
## <제목> — <YYYY-MM-DD> · <유형: 이벤트 | 홍보 | 산출물 | 계약>
- **내용**: 한 줄 요약
- **혜택/조건**: (이벤트·홍보) 혜택 · 참여 조건
- **기간**: 시작 ~ 종료 (해당 시)
- **대상/채널**: 대상 · 노출 위치(앱 이벤트 모달 / 카톡 / SNS / 지자체 등)
- **상태**: 초안 | 예정 | 진행중 | 종료
- **자료**: 파일 경로 또는 링크
```
- 해당 없는 줄은 생략. 날짜는 세션 컨텍스트의 currentDate(절대날짜).

## B) 정리/요약 (요청 시: "노션 자료 정리/모아줘")
1. `notion-fetch` 로 전체를 읽는다.
2. 최상단에 `## 📋 현황 (YYYY-MM-DD 기준)` 을 만들거나 갱신:
   - 유형별 개수, **진행중인 이벤트**(기간·상태) 를 먼저 모아 나열.
   - 종료된 이벤트는 상태를 `종료` 로 갱신.
3. 히스토리는 지우지 않는다.

## 노션이 연결돼 있지 않으면 (중요)
`notion-search`/`notion-fetch`/`notion-update-page` 도구가 이 세션에 없으면:
1. 대신 **`docs/NOTION_LOG.md`** 에 위 A) 형식 그대로 최상단에 추가한다(없으면 생성). 이게 임시 버퍼 — 아무것도 잃지 않게.
2. 사용자에게 "노션 미연결이라 `docs/NOTION_LOG.md` 에 담아뒀고, 노션 연결되면 이 파일 내용을 페이지로 올리겠다"고 알린다.
3. 다음에 노션이 연결되면 `docs/NOTION_LOG.md` 의 미반영 항목을 페이지로 올리고, 올린 항목은 파일에 `[노션 반영됨]` 표시.

## 원칙
- 노션·파일 쓰기는 사용자 워크스페이스 변경 — **누적(append)은 자유**, 대규모 재작성/삭제 전엔 확인.
- 실제 수치·조건은 확정본 기준으로. 미확정은 `[ ]` 로 남긴다(예: 경품 상세, 수수료율).
- 이벤트는 **기간·상태**를 꼭 남긴다(종료일 지나면 상태 갱신 가능하도록).
